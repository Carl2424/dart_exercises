Student Income and Expenses

Name: Carl John  
Section: BSIT 3.2
Scenario

This program represents a student working at McDonald's for 6 hours per day. It calculates income received every 4th and at the end of the month, 
then subtracts expenses for breakfast, motorcycle gasoline, and the monthly motor loan.

Dart Concepts Demonstrated
- String
- int
- double
- bool
- Arithmetic operators
- Comparison operator
- String interpolation
- print() statements
